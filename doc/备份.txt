- `最终地址`按照最终地址判定规则填写

只提取到一个地址时也可以保持`校区`为空，除非必须依靠校区名称区分地址

### 多个明确校区

如果官网明确给出多个“校区名称+地址”，每个校区输出一行。

每一行重复填写该学校的教育部字段、办学层次、院校标签和办学性质。

每个校区的官网地址、地图地址、最终地址分别填写。

### 校区保留

只输出能够确认位于输入城市的校区。

城市判断顺序：

1. 地址明确包含标准城市名。
2. 页面上下文明确说明该地址位于标准城市。
3. 地址只写区县，但该区县可以可靠确认属于输入城市。

如果无法确认行政归属：

- 不输出该校区地址。
- 在查询日志中记录`校区城市归属无法确认`。
- 不得猜测。

### 多地址但没有校区名称

如果官方页面给出多个地址，但没有给出对应校区名称：

- 每个地址分别输出。
- `校区`填写`未注明校区`。
- 不得根据地名自行编造校区名称。

### 没有找到输入城市内地址

如果官网检索和地图兜底均未获得输入城市内有效地址，仍保留该学校的一行基本信息：

- `校区`留空；
- `官网地址`留空；
- `地图地址`根据实际查询结果填写或留空；
- `最终地址`留空；
- `来源链接`填写已确认的官网首页；如果官网也未确认则留空；
- 在查询日志中记录失败原因。

这样保证主表不会因为官网查询失败而漏掉教育部名单中的学校。

### 去重

主表按照下列组合去重：

`学校标识码 + 校区 + 标准化地址`

不得通过模糊地址相似度合并不同校区。

## 查询日志

`查询日志`工作表至少包含：

| 字段           | 内容                                           |
| -------------- | ---------------------------------------------- |
| 学校名称       | 教育部学校名称                                 |
| 查询状态       | 成功、部分成功、失败、待核验                   |
| Web Search次数 | 0或1                                           |
| 访问页面数     | 0、1、2、3                                     |
| 已访问链接     | 用换行分隔                                     |
| 地图验证状态   | 一致、部分一致、未找到、未验证、兜底           |
| 失败或异常原因 | 地址缺失、官网未确认、城市归属不明、地图冲突等 |
| 查询时间       | YYYY-MM-DD                                     |

查询日志以学校为单位，不以地址记录为单位。

`失败或异常原因`只记录实际失败、缺失、冲突或待核验事项。

- 查询状态为`成功`且不存在异常时，该字段必须留空；
- `部分成功`填写未获取到的校区或其它缺失原因；
- `失败`填写具体失败原因；
- `待核验`填写具体冲突或异常原因。

正常的地址获取过程、成功依据、校区确认说明不得写入`失败或异常原因`。

## Excel格式

生成工作簿时：

- 学校标识码设置为文本格式。
- 时效和查询时间使用真正的日期值，显示格式为`yyyy-mm-dd`。
- 表头加粗并设置清晰底色。
- 冻结首行。
- 启用自动筛选。官网地址、
- 地图地址、最终地址、来源链接和失败原因允许自动换行；
- 来源链接保留完整URL，原则上不启用自动换行，并设置足够列宽，避免URL在字符中间产生视觉断行；
- 设置合理列宽，避免表头和关键内容被截断。
- 不创建无内容的默认工作表。
- 来源链接保留完整URL。

## 完成前验证

输出前必须执行以下检查：

1. 教育部名单中所有`所在地 == 标准城市名`的学校都必须至少出现在主表一次。
2. 主表中学校标识码去重数量必须等于教育部名单筛选学校数量。
3. 多校区拆行后，主表总行数可以大于学校数量。
4. `办学层次`必须保留教育部原始值，只能据源表填写。
5. 只有办学层次为本科的院校才参与985、211匹配。
6. 非空`来源链接`必须是学校官方域名或官方二级单位域名；地图兜底记录允许来源链接为空。
7. 每所学校Web Search次数不得超过1。
8. 每所学校访问页面数不得超过3。
9. 不得包含重复的`学校标识码+校区+地址`组合。
10. 有有效官网地址时，`最终地址`必须等于`官网地址`。
11. 使用地图兜底时，`官网地址`必须为空，`最终地址`必须等于`地图地址`。
12. 检查主表和查询日志是否存在明显空表、乱码、科学计数法或截断问题。
13. 如果验证失败，修复后重新生成，不得直接交付错误文件。

## 失败处理原则

遇到无法确认的信息时：

- 对无法确认的字段留空；
- 除本Skill明确允许的地图兜底外，不使用第三方网站补齐地址；
- 不根据模型记忆填写。
- 在查询日志中说明具体原因。
- 继续处理其他学校，不因单所学校失败而终止整个任务。

只有输入文件缺失、工作簿无法读取或输出文件无法创建时，才终止整个任务。

## 最终回复

完成后向用户说明：

- 标准化后的城市名称
- 筛选到的学校数量
- 主表地址记录数量
- 查询成功、部分成功、失败和待核验的数量
- 输出文件名和保存位置

不要输出大段中间搜索过程，详细信息保留在`查询日志`工作表中。
