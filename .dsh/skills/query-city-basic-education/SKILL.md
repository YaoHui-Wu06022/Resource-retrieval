## 目标

输入一个中国城市，按其直接下级行政单位查找并筛选高质量政府非高校学校名录。幼儿园、小学、初中和高中是必须分别核验的基础学段，不是检索范围上限；来源发现和质量判断是当前主要工作。

## 运行前确认

- 先询问用户使用哪个 Python 环境或解释器，确认后再运行脚本。
- 高德行政区域查询需要从进程环境或工作区 `.env` 读取 `AMAP_KEY`。
- 提取脚本需要 BeautifulSoup、lxml、pandas、openpyxl、xlrd 和 PyMuPDF；读取 Word 还需要 LibreOffice。
- 缺少环境、密钥或公共组件时停止并说明，不自行安装或编写替代脚本。

## 1. 取得检索单元

运行 `components/normalize_city.py`，输入参数 `--city` 为用户城市。

输出中的 `subdivisions` 是直接下级行政单位列表。每项都是一个独立检索单元，必须各处理一次，不由 Agent 增删、合并或改名。

在当前目录创建 `Basic_Education_<标准城市名>_<YYYY-MM-DD>` 输出目录，并按每个 `subdivisions[].name` 创建子目录。后续该行政单位的来源文件只保存到对应子目录。

## 2. 发现骨干来源

逐检索单元使用 Agent 自有 Web Search，先查对应教育行政部门或政府栏目，再查上级政府门户和政府数据开放平台。市级部门明确覆盖该单元的来源也可以使用。

对幼儿园、小学、初中和高中分别检索，不得因已经找到其中一类、几类或一份综合来源而提前结束。综合来源只有实际列出某类学校时才计入该类覆盖；一贯制学校、完全中学等按来源明确标注的学段计入相应类别。政府栏目或名录还公开特殊教育、中等职业教育、职业高级中学、技工学校、专门学校或其他非高校类型时，也必须纳入检索和提取，不得用固定类别表排除。

优先检查学校介绍、学校一览表、基本信息、招生入学和公开数据栏目。候选来源按日期从新到旧探查，以官方性、时效性和实际信息量判断质量，不按 HTML、Excel、Word、PDF 的格式排序。

根据来源形态处理：

- 分类分页 HTML：遍历相关类别的全部分页，将其视为一个来源；列表已有所需字段时不逐校访问详情页。
- 附件分散的栏目：先读页面和附件标题，只下载能够贡献目标学校信息的附件。
- 长 PDF 或 Word：检查全文、目录、附件标题和尾部附表，不得只看标题或开头页面。
- 单一来源不完整：保留其已覆盖范围，并针对缺失类别继续检索，直到找到合格官方来源或已检查完可用的教育行政部门、政府门户和政府数据平台。

发现骨干来源后逐项核对四个基础学段和已经发现的其他官方学校类型。学校类型以逐行表格字段、明确分类表或栏目为准，不根据校名猜测；招生计划中的逐校清单可以作为名录，但不能据此推断未提供的地址。只有取得不存在明显范围缺口的合格官方名录时，该类型才算完整覆盖；仅有公办、民办、部分学段或部分学校的清单时仍需继续查找补充来源。

入选来源必须由政府或教育行政部门发布，正文或附件实际包含非高校学校名录或结构化清单。地址不是入选条件，学校类型不作为排除条件。

不得使用地图、百科、媒体、自媒体、择校网站或第三方学校数据库。

## 3. 保存并记录来源

每个入选来源记录：行政单位名称、来源标题、发布部门、发布日期或更新时间、直接链接、文件格式、覆盖学校类型及是否包含地址。

每个检索单元还必须在 `sources.json` 的 `school_type_coverage` 对象中记录覆盖状态。“幼儿园”“小学”“初中”“高中”是必有键；政府来源中出现的其他非高校学校类型按原文动态增加。状态只能是 `covered`、`partial`、`no_official_source` 或 `source_unusable`。未找到资料前必须完成针对该类型的独立检索，不能把尚未检索记为无来源。

来源通过质量判断后立即下载，保留原始文件格式和文件名。分页 HTML 保存全部名录页；通知页仅用于说明附件出处时只记录页面链接并下载原始附件。不得下载未入选的候选来源，也不得用转换后的文件代替原始文件。

PDF 先检查文本层：缺少字符映射时补充 CMap；没有文本层的扫描件使用用户确认的 OCR 工具。保留原文件，把可检索 PDF 记录到来源的 `derived_files` 后重新检查，不得用派生文件替换原文件，也不得把两种情况混为同一解析错误。

## 4. 制定提取计划

运行 `scripts/build_school_records.py inspect`，输入 `--input sources.json` 和 `--output extraction_plan.json`。

Agent 只复核文件、分页、工作表、表格或页码，以及学校列、地址列、学校类型和办学性质的列或固定值、向下填充列和排除行，不手工抄写记录。确认后的规则将 `approved` 设为 `true`，对应来源将 `review_status` 设为 `ready`。`needs_ocr`、文本映射异常或没有建议规则的来源必须先处理，不能直接标记为完成。

## 5. 提取学校与地址

运行 `scripts/build_school_records.py extract`，输入 `--plan extraction_plan.json` 和 `--output address_records.json`。

逐条业务信息只有：

- `place_name`：学校名称；来源将校区、分校或教学点单列时，与学校名称拼接。
- `original_address`：来源中的原始地址；来源未提供时保留为空。
- `attributes.school_type`：规范后的学校类型；一贯制统一为“X年一贯制学校”，并列学段逐项规范为“幼儿园、小学、初中、高中”，其余已知类型使用正式名称，未知类型保留原文。
- `attributes.school_nature`：明确时规范为“公办”或“民办”；不能归入二者但有官方表述时保留原文，无法判断时为空。

电话及其他字段不提取。脚本另保留公共层要求的来源性质、来源定位和行政单位；`source_nature` 固定为 `government_information`。

只有输出 `stage = address_records` 且 `error_count = 0` 时才能进入公共地址层。存在未复核来源、空规则或规则未提取到学校时，脚本输出 `address_records_incomplete` 并失败。根据实际提取结果重新核对覆盖范围，不能只凭来源标题判定完成。

## 6. 处理地址

对每个已生成 `address_records.json` 的行政单位运行 `components/process_addresses.py`，输入 `--input <行政单位目录>/address_records.json`，输出 `--output <行政单位目录>/processed_address_records.json`。

政府信息中的完整地址规范化后直接成为最终地址，不调用地图；地址为空或不完整时才允许按公共规则调用地图兜底。目标城市冲突或没有合格兜底结果时，`final_address` 保持为空。

## 7. 输出工作簿

所有行政单位完成地址处理后运行 `scripts/build_excel.py`：

- `--input-dir`：城市输出目录；
- `--output`：`<城市输出目录>/基础教育学校查询_<标准城市名>_<YYYY-MM-DD>.xlsx`。

脚本在每个存在处理结果的行政单位目录生成 `基础教育学校信息_<行政单位>.xlsx`，再生成城市最终工作簿。最终工作簿第一张“学校信息”是全部行政单位的总表，后续按行政单位各建一张同名工作表。各行政单位表分别编号，总表重新编号；只输出 `final_address` 非空的记录。

行政单位表和总表字段相同：

| 列 | 字段 |
| --- | --- |
| 序号 | 工作簿展示序号 |
| 行政单位 | `attributes.administrative_unit` |
| 学校名称 | `place_name` |
| 学校类型 | `attributes.school_type` |
| 办学性质 | `attributes.school_nature` |
| 最终地址 | `final_address` |
| 信息来源 | `source_reference` 中的来源 URL、原始文件名和原始行号 |

行政单位中间工作簿只含一张“学校信息”表；城市最终工作簿包含“学校信息”总表和各行政单位分表。所有单元格居中且不缩进、不自动换行；表头冻结并启用筛选，来源链接可点击。“信息来源”只展示 `来源 URL | 原始文件名 | row 原始行号`，完整文件内定位继续保留在 JSON 中。

## 完成检查

每个检索单元必须根据全部覆盖状态记录一种总体状态：

- `completed`：四个基础学段和已经发现的其他官方学校类型均为 `covered`，且可用来源已经提取；
- `partial`：已有可用来源，但任一必查学段或已发现类型为 `partial`、`no_official_source` 或 `source_unusable`；
- `no_official_source`：没有找到合格政府来源；
- `source_unusable`：找到了政府来源，但没有任何来源能够访问或解析。

不得静默遗漏检索单元、四个基础学段或已经发现的其他官方学校类型，不得使用第三方来源补齐，也不得继续查询更低一级行政单位。政府未公开某类名录时保留已取得结果并如实记录缺口，不得把该检索单元标记为 `completed`。

最终还必须确认：每个进入输出的行政单位都有 `processed_address_records.json` 和行政单位工作簿，城市总表行数等于全部行政单位工作簿行数之和，且所有输出行的最终地址均非空。
